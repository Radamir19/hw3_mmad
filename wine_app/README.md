# Качество вина

Приложение оценивает одно вино или CSV, показывает метрики при разных порогах и коэффициенты модели. Модель уже обучена, внутри приложения обучение не запускается.

Python 3.12. Из корня репозитория:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r wine_app/requirements.txt
streamlit run wine_app/app.py
```

В Windows окружение включается командой `.venv\Scripts\activate`.

Для пакетного прогноза нужен CSV с теми же 12 признаками, что в `wine_app/test.csv`, без `target`. `is_red`: 0 — белое, 1 — красное. Порог общий для всех вкладок.

`st.cache_resource` хранит один объект модели на сервере. `st.cache_data` кэширует таблицу и вероятности, возвращая копии данных. Без декоратора `joblib.load` заново читает модель при каждом действии пользователя.

Для Streamlit Community Cloud: выбрать этот репозиторий, ветку `main`, файл `wine_app/app.py` и Python 3.12. Зависимости находятся рядом с приложением.
